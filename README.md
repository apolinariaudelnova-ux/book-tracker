# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с сохранением в JSON.

## Как запустить

1. Убедитесь, что установлен Python 3.x.
2. Выполните команду: `python main.py`.

## Пример работы

Меню:
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход

## Функционал
* Добавление книг с проверкой на дубликаты.
* Просмотр списка книг.
* Расчёт средней оценки.
* Статистика по авторам.
* Удаление книг.
